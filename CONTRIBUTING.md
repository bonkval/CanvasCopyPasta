# Contributing

Contributions that improve Canvas compatibility, accessibility, and extraction accuracy are welcome.

1. Do not include real student data, login details, or active assessment content in issues, fixtures, screenshots, or commits.
2. Create a sanitized minimal fixture for an extraction bug.
3. Run `npm run check` before submitting a change.
4. Explain which Canvas quiz engine and browser were tested.
5. Keep the existing compact green-and-gold appearance unless a design change is discussed first.

Features designed to conceal prohibited assistance, automate answer submission, or bypass academic-integrity controls are out of scope.
